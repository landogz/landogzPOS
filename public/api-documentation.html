PharmaPOS / Landogz POS — API Documentation

Base URL: http://localhost:8000 · Prefix: /api/v1 · Auth: Bearer token (from POST /auth/login)

Single-page reference with example code in cURL, Ruby, Python, PHP, Java, C# (.NET), JavaScript. Use the language tabs above each request. Replace YOUR_TOKEN with data.token from the login response.

Branch scoping: super_admin and admin see all branches (products, inventory, reports). manager, inventory_manager, and cashier see only their assigned branch; they must have branch_id set (403 otherwise). List responses include branch / branch_id where applicable for grouping.

Authentication

POST/auth/login

Login with email and password. Returns token, user, branch, permissions.

Body (JSON):
{"email":"admin@demo.pharmapos.test","password":"password"}
curl -X POST "http://localhost:8000/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{"email":"admin@demo.pharmapos.test","password":"password"}'
require 'net/http'
uri = URI('http://localhost:8000/api/v1/auth/login')
req = Net::HTTP::Post.new(uri)
req['Content-Type'] = 'application/json'
req['Accept'] = 'application/json'
req.body = '{"email":"admin@demo.pharmapos.test","password":"password"}'
res = Net::HTTP.start(uri.hostname, uri.port) { |h| h.request(req) }
puts res.body
import requests
r = requests.post(
    'http://localhost:8000/api/v1/auth/login',
    json={'email': 'admin@demo.pharmapos.test', 'password': 'password'},
    headers={'Accept': 'application/json'}
)
print(r.json())
$ch = curl_init('http://localhost:8000/api/v1/auth/login');
curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => ['Content-Type: application/json', 'Accept: application/json'],
    CURLOPT_POSTFIELDS => json_encode(['email' => 'admin@demo.pharmapos.test', 'password' => 'password']),
    CURLOPT_RETURNTRANSFER => true
]);
$res = curl_exec($ch);
curl_close($ch);
print_r(json_decode($res, true));
HttpClient client = HttpClient.newHttpClient();
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("http://localhost:8000/api/v1/auth/login"))
    .header("Content-Type", "application/json")
    .header("Accept", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString(
        "{\"email\":\"admin@demo.pharmapos.test\",\"password\":\"password\"}"))
    .build();
HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
using var client = new HttpClient();
var body = new { email = "admin@demo.pharmapos.test", password = "password" };
var content = new StringContent(
    System.Text.Json.JsonSerializer.Serialize(body),
    Encoding.UTF8, "application/json");
client.DefaultRequestHeaders.Accept.Add(
    new MediaTypeWithQualityHeaderValue("application/json"));
var response = await client.PostAsync(
    "http://localhost:8000/api/v1/auth/login", content);
Console.WriteLine(await response.Content.ReadAsStringAsync());
const res = await fetch('http://localhost:8000/api/v1/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'Accept': 'application/json' },
  body: JSON.stringify({ email: 'admin@demo.pharmapos.test', password: 'password' })
});
const data = await res.json();
